# 技术决策

1. Go 单体、SQLite WAL 和外键，React/TypeScript/Vite 静态资源嵌入。Go 1.25 为引导下限，项目固定 go1.26.9；原 Go 1.26.5 的可达标准库漏洞已通过升级修复，复扫无已知漏洞。源资料只读。当前没有同名工程，直接新建 openreading。
2. PDF.js 6 使用 DocumentInitParameters；文档资源由 loadingTask.destroy 释放。原生页坐标存储四边形，按视口转换重投影。单页加载，明确不支持跨页选区。扫描页仅页级笔记。
3. epub.js 0.3.93 保留官方 0.3 API，覆盖其有漏洞的 XML 依赖到 0.9 系列；锁文件固定实际版本。0.4 分支依赖更旧，未采用。重排以 CFI 和原文二次校验。禁书内脚本和远程资源。
4. 规范文本保存 Unicode code point 半开范围。DOM Range/CFI 使用 UTF-16；显式转换。跨版本只接受带完整相邻上下文的唯一精确匹配。
5. 缺少系统钥匙串集成时仅会话内存凭据。模型配置可持久化，密钥不入数据库和备份。模拟供应商仅显式创建，界面标明模拟；不自动消费任何已有环境密钥。
6. 本机服务每次启动生成配对码，本次运行期间可供多个浏览器分别登录，由表单 POST 建立独立的 HttpOnly SameSite=Strict 会话和 CSRF 令牌。新增登录不撤销现有会话；重启轮换配对码和全部会话。每次写入校验 Origin 与 CSRF；Host 只允许 loopback。普通内容和模型没有工具权限。
7. M0 实验后沿用四格式 ReaderAdapter。PDF.js 6 需要同时设置文本层缩放取整 CSS 变量，原生 CropBox/旋转与浏览器视口分别转换；不得直接保存屏幕坐标。取消渲染的拒绝立即捕获，防止切页产生未处理异常。
8. EPUB 保持书内脚本关闭。WebKit 对禁脚本 iframe 的子事件有限制，由父页面读取同源、稳定且改变的 Selection/CFI。已捕获选段独立于原生 Selection；输入评论前清除原生选区。初始化和销毁串行，队列停止且过期位置回调不再访问销毁后的书籍。
9. 未确认的发送操作连同幂等键保存在 IndexedDB，重开先查询服务器结果，再恢复草稿或已有线程；不通过自动重发规避未知状态。草稿加载完成前输入暂不可用，避免迟到的恢复结果覆盖新输入。
10. 成功导入的主副本即使尚未打开也必须进入完整备份。仅登记、从未缓存的连接目录文档单列为“需要重新连接”，不能用缓存版本数代替全部文档覆盖率。
11. 连接来源按物理文件身份辅助发现，最终仍以原路径或显式绑定确认；inode 复用不能把独立文件误合并。增加身份索引，10,000 文件扫描不再做平方级逐条匹配。

核对来源：PDF.js 官方 examples、epub.js 官方仓库、react-markdown 官方仓库、DeepSeek Chat Completions 官方文档，2026-10-18。版本和依赖以 package-lock.json 与 go.sum 为准。
