# 已知边界与待验证项

1. 真实外部模型 API 没有配置密钥。本次只验证显式模拟服务与本机 HTTP 协议服务的流式、错误、超时、取消和配置固定；不将这些结果等同于真实模型连接、费用或解释质量通过。
2. 当前默认支持单人本机书库与同一局域网手机同步。管理界面仅监听 127.0.0.1；用户开启后，独立 TLS 局域网端口仅提供配对与已授权同步。可选私人云端仍由反向代理接入。没有多租户权限、实例间自动同步或 Agent 命令执行功能。
3. V1 支持 Markdown、TXT、文字型 PDF、可重排 EPUB。扫描页仅页级笔记；无 OCR。DOCX、固定版式 EPUB、HTML、图片问答和跨文档检索未纳入完整支持。
4. PDF 只允许单页连续选区，跨页需要分段；EPUB 跨章同理。双栏、断词等提取保留实际文本，不承诺自动语义重排或恢复所有特殊排版。公式、图表、竖排和加密材料需按实际可选能力判断。
5. 大 Markdown/TXT 的整篇 DOM 和解析延迟没有达到 PDF 按页加载的同等验证范围。提取产物请求上限 4 MiB，超限会可见失败，不会保存截断或错误锚点；建议拆分超长文本。
6. API Key 为会话内存存储，没有调用系统钥匙串。服务重启或从备份恢复后需要重新绑定。价格未配置，不估算费用；未返回 usage 的请求显示用量未知。
7. 内容变化后只有完整原句与上下文的唯一精确匹配可自动定位。PDF/EPUB 跨版本映射保守地要求人工确认；同一版本缩放或重排不需要重新绑定。
8. 备份上传上限 1 GiB、展开上限 2 GiB。未打开的连接目录不自动打包；界面显示可离线恢复版本和未缓存版本。备份不包含密钥。
9. 主运行环境为 macOS Apple Silicon。Firefox 与 WebKit 验证结果需按目标浏览器复测；WebKit 测试不等同于对用户已安装的每个 Safari 版本逐一认证。Linux 源码可构建，若提供交叉构建，必须与本机已运行验证区分；Windows x64 已提供原生服务及 Electron 构建；桌面预览包尚未商业签名/公证。
10. 模型平台预设当前只适配 Chat Completions 文本接口，不支持仅提供 Responses、Anthropic Messages 或 Gemini 原生接口的模型。获取到的目录仍需选择兼容的文本模型；预算和能力映射由同一提供方下的模型共用，可在高级设置调整。
11. 500 页 PDF 的内存记录是测试浏览器各进程的采样 RSS，不是连续操作系统峰值，也不是 500 页扫描大图或全部异常 PDF 的总体结论。这类基准需按实际文档和设备复测。

特殊文件可以可见失败或降级，但不得静默丢批注、错定位、跨工作区发送材料、未经确认改写原始资料、泄露密钥或宣称不完整备份成功。遇到这些情况应阻止发布并先修复。
