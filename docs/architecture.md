# OpenReading 工程说明

`cmd/openreading` 负责启动、loopback 监听和进程退出。`internal/server` 包含 SQLite 迁移、工作区、来源、快照、批注、上下文、问答队列及数据服务；`web/src/readers` 是格式适配器，`web/src/main.tsx` 为工作区与阅读交互。Vite 构建结果嵌入 Go 可执行程序。

## 身份与版本

Document、SourceEntry、WorkspaceDocument 和 DocumentVersion 分别表示文档身份、路径绑定、工作区学习身份和内容快照。相同内容只去重 blob，不因哈希相同合并文档。跨工作区复用物理文件时同时复核文件标识和实际文件身份，防止失效路径与 inode 重用误合并。

来源通过 os.Root 读取，在实际打开时拒绝绝对路径、父目录穿越与符号链接越界。读取和扫描不修改原文件，只有明确选择删除原始文件才会执行删除；快照以流式复制和 SHA-256 捕获，检查前后状态，有限重试，原子发布并同步文件目录。登记目录只读元数据。fsnotify 事件经去抖后复核元数据，启动、重开、手动刷新及周期扫描补偿漏事件。

提取产物保留解析器、规范化、清洗版本以及稳定文本块。当前实现按正文、PDF 页或 EPUB 章节保存产物。选区采用 Unicode code point 半开范围；DOM 与 CFI 的 UTF-16 单位显式转换。PDF 保存原生坐标四边形，EPUB 保存 CFI。服务端验证身份、提取文本、原句、范围、预算与清单关联；PDF/EPUB 的语义提取正确性依赖受测试的阅读适配器，不宣称 Go 重新解析证明原文。

原始锚点不可变。自动映射与手动重新定位分别写入 resolution；新问题可使用已确认的新定位，旧问答仍绑定旧快照。无法唯一精确匹配时拒绝静默迁移。历史资源只读已捕获清单。

## 保存与运行

SQLite 开启外键、WAL、FULL 同步和忙等待。写事务串行化；笔记更新使用 revision，问题创建使用 scope、clientRequestId 和请求哈希。客户端 IndexedDB 保存草稿和未确认操作；网络响应丢失后通过幂等记录检查已提交结果。

问题、上下文、来源、占位回复和 queued 运行在一个事务中保存。最多两个全局运行、每线程一个。每个运行固定端点、模型、能力映射与凭据版本。提供方保存端点、一份会话凭据、默认模型和多个模型 ID；模型列表与平台标识存入现有 config_json，无需数据库迁移。旧单模型配置按一个模型兼容。消息使用 modelProfileId 指定提供方，可选 modelId 指定已配置模型，省略时沿用默认模型；服务端验证归属并将实际模型写入上下文快照。删除提供方采用归档，保留历史外键，并阻止运行中删除。

上游 Chat Completions 转换为内部事件。文本约每 250 ms 或 1 KB 合批，落盘后才推送 SSE；完成、取消、错误与结束事件原子提交。重连返回带 lastSeq 的全量快照，再传新事件。客户端按序号去重。未知引用保留文字但不会生成证据链接。

不自动重试上游请求。重试是用户显式发起的新运行，保留旧回复并默认复用原上下文。程序重启将非终态运行标为 interrupted。数据目录有进程文件锁，重复启动不能抢先改写运行状态。

## 隐私边界

本次服务配对码允许多个浏览器分别建立独立的 HttpOnly、SameSite=Strict 会话和 CSRF 令牌，新增登录不使已有会话失效；服务重启后配对码及全部会话更新。写操作检查对应会话的 CSRF，所有 API 检查 Host 与 Origin。原文、批注和 SSE 读取均需会话。模型没有工具、文件读取或命令执行入口。

API Key 只保存在进程内存，配置字段采用白名单，日志只记错误类型和匿名请求 ID。服务商启用记录绑定工作区及目标地址。地址或协议变化后解除当前凭据绑定及旧启用目标；旧凭据版本仅供已冻结的在途运行使用。未保存配置也可显式获取模型目录，仅在目标与原配置相同时复用已绑定密钥。普通笔记不创建模型运行。输入预算为产品预算和模型容量扣除生成预留、安全余量后的较小值；选段与问题不静默截断。

Markdown 禁止原始可执行 HTML；EPUB 预清洗并保持 sandbox 书内脚本关闭，远程资源默认阻断。WebKit 在脚本禁用的 iframe 中不派发部分子事件，因此父容器仅观察稳定、变化的选区 CFI；不通过打开书内脚本解决兼容性。资源和字体随程序打包。

## 备份

备份使用数据库一致性逻辑导出，复制过程持有写锁，版本与资源引用集合稳定。导入与备份串行，未打开的应用管理副本也转换为不可变版本。清单校验实际 blob 哈希，受保护文件缺失即失败。

恢复先验证 ZIP、哈希、版本、空间与字段，暂存后发布 blob，并在单个事务中重映射工作区、来源、版本、产物、锚点、消息、上下文、运行和事件。恢复凭据解绑、来源断开、运行终止；快照哈希按重映射后的结构重新计算。

原设计正文保存在 `design-v1.txt`；技术取舍见 `decisions.md`。

云端模式通过 `--public-url` 明确绑定单个 HTTPS 来源，`OPENREADING_ACCESS_CODE` 从服务器受保护的环境文件载入并保持稳定；会话 Cookie 标记 Secure，重启后仍需重新登录。应用保持 loopback 监听，由你配置的 HTTPS 反向代理接入；云端禁止服务器目录选择和目录连接，仅允许上传。云端与本机实例的数据目录独立，不自动同步电脑资料。

原文件删除先在同一目录暂存，数据库事务保存失败时恢复原路径；事务提交后才清理暂存文件。公开发行版默认不配置云端地址。
