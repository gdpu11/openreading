# 视频解说（首版）

在桌面或浏览器阅读器的工具栏点击 **视频解说**。它是带旁白和字幕的交互图解播放器，可以按片段跳转，并带着出处回到阅读器提问或写笔记。

## 使用

1. 在 **设置 → 模型与隐私** 中配置兼容 Chat Completions 的文本模型，绑定凭据，并为当前工作区启用。
2. 打开 Markdown、TXT、EPUB 或有文字的 PDF，点击 **视频解说**。
3. 选择“约三分钟导览”或具体章节 / 页面，可填写最多 300 字的阅读目标。
4. 点击 **预览讲解内容**。原文先在本机提取，确认本次发送的全部片段、模型和覆盖范围。
5. 点击 **确认生成讲解**，才会请求所选模型。该请求可能产生服务商费用，没有后台自动生成或失败后自动重试。
6. 播放、暂停、逐句跳转、调整速度，或按章节跳转。可展开完整讲稿。
7. **定位原文** 回到引用位置；**去原文提问** 和 **写笔记** 将当前讲解与原文放入笔记区草稿，仍由用户编辑、确认发送或保存。

目标时长约三分钟，不等于生成耗时，也不是承诺三分钟讲完一本书。实际播放时长根据返回的讲稿估算。短材料不要求扩写凑时长。

## 画面与旁白

- 讲解模型生成结构化讲稿、概念卡片、流程步骤或两项对比，使用固定界面渲染。不会执行模型返回的 HTML、SVG 或代码，也不会加载模型生成的远程图片地址。
- 中文旁白使用设备已有的本地中文系统语音，不向第三方语音服务发送讲稿。缺少本地中文语音时给出明确提示，可手动选择静音图解播放。
- 字幕与逐句旁白同步；在不提供细粒度语音进度的设备上，以短句作为字幕和跳转边界。时间轴是估算，实际语速受系统语音影响。
- 暂停 / 改变速度后按系统语音提供的词边界继续；不提供边界的设备可能从当前短句重新开始。
- 桌面窗口和窄屏浏览器使用同一播放器。原生手机的离线阅读界面本次未增加模型管理或生成权限。

## 来源与覆盖范围

- 只使用当前文档版本的本机文字索引。Markdown 根据实际显示的标题拆分；EPUB 按章节、PDF 按页面提供范围。
- 在模型预算内的短材料完整发送。长材料使用明确展示的均匀抽样，预览和播放器都会标注“原文抽样”，不能据此声称模型通读了全书。
- 每个片段必须引用本次提供的有效来源编号。结构、来源编号或完整性检查不通过的脚本不会缓存为成功结果。
- 出处编号有效不代表 AI 的解释必然正确。播放界面保留原文片段，用户可以核对具体论断；例子、推断和原文事实仍需区分。
- 扫描 PDF 需要先识别文字。加密 PDF 的独立全文提取不共享阅读器中临时输入的密码。

## 缓存与取消

完成的讲稿保存在当前书库数据目录的 `derived/video-guides/`，按工作区文档与不可变版本隔离。更换服务端临时端口或重启应用不会丢失缓存；无需模型凭据即可读取已有讲稿。

相同来源、目标、模型配置和脚本规则的生成会复用已有缓存。明确选择“重新生成”才会再次请求模型；相同请求编号的重试复用原结果。模型请求和普通问答共用最多两个并发名额。关闭窗口或取消生成会中断当前请求，不自动重发。

界面列出最近 40 个完成结果。派生讲稿缓存不属于正式笔记，不进入书库备份、ORD 导出或手机同步；需要保留的收获请使用 **写笔记** 保存为正常笔记。当前版本不会导出 MP4，也不调用独立的视频画面生成服务。

## 验证边界

`internal/server/video_guides_test.go` 覆盖发送预览、工作区启用、预算抽样、版本和章节隔离、缓存 / 请求去重、显式重新生成、无效脚本、并发限制及取消上游请求。`web/src/video/types.test.ts` 覆盖章节拆分、字幕时间轴、Unicode 边界和原文引用定位。

真实模型的解释质量与生成速度取决于用户配置的服务。自动测试使用隔离书库和本机协议模型，不读取私人书库或自动消费已有外部模型凭据。
